Linear entanglement suffices for $f$-routing

Kevin Bogner

TL;DR

Abstract
In $f$-routing, Alice receives an $n$-bit string $x$ and an unknown qubit, and Bob receives an $n$-bit string $y$. They share a state prepared in advance and exchange one simultaneous message each. The party selected by the Boolean function $f(x,y)$ must then recover the unknown qubit without further communication. To perform $f$-routing successfully, Alice and Bob need to share entanglement that scales with $n$ for some functions $f$, but the lower and upper bounds for the entanglement are not tight. This paper shows that $2n+2$ shared EPR pairs suffice for every function $f$. The best previous bound that holds for all functions is a shared state of $2^{O(\sqrt{n\log n})}$ qubits. The new strategy moves the cost from the shared state to the messages: Alice sends an exponentially long message of $2^{n+1}+1$ qubits, while Bob sends only classical bits. When the messages are counted towards the resources as well, the previous strategy remains the cheapest known. The result also limits lower bounds that count only the shared state: they cannot exceed a linear number of EPR pairs. The result is formalized in Lean.
Problem

In f-routing, Alice and Bob must route an unknown qubit to the party selected by a Boolean function f(x,y) after one simultaneous message exchange. It was open how much shared entanglement is needed. The best upper bound for all functions was 2^{O(sqrt(n log n))} qubits.

Approach

Alice teleports the qubit, which encrypts it with a key held in superposition. She applies operators built from Pauli X and Z products whose commutation is decided by f(x,y). Bob performs a measurement in a basis that depends on y and sends only classical bits. Alice sends an exponentially long quantum message of 2^{n+1}+1 qubits. Theorem 1 is formalized in Lean.

Results

2n+2 shared EPR pairs suffice to route perfectly for every Boolean function. Lower bounds that count only the shared state therefore cannot exceed linear in n. The Lean proof uses only Lean's three standard axioms.
