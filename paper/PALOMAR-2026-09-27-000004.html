Problem

Determine the zero-forcing number of the generalized Petersen graphs P(n,3) for all sufficiently large n. The value 8 for n >= 13 was stated as Conjecture 5 in Arnav Krishnan's July 2026 correction preprint.

Approach

A Lean 4 development states the zero-forcing number of P(n,3) and proves it for every natural number n >= 13. The repository supplies an original proof of the conjectured statement rather than formalizing an existing written proof, and the proof is kernel-checked.

Results

A machine-checked theorem that the zero-forcing number of P(n,3) is exactly 8 for all n >= 13, settling the cited conjecture.
