Undirected Network Coding and Faster External-Memory Integer Sorting

Baochun Li, Zongpeng Li, Sirui Liu

TL;DR
The sorting algorithm's correctness and I/O complexity bound, and the strict coding-over-routing advantage, are formalized in Lean 4 with Mathlib in a public repository.
Abstract
Network coding allows intermediate nodes to combine messages. Fractional routing instead splits each message among source-destination paths and forwards its parts without combining different messages. For undirected networks carrying independent messages between multiple source-destination pairs, the multiple-unicast conjecture asserts that the two methods achieve the same combinations of message rates. We give a finite counterexample and use its linear structure to accelerate external-memory integer sorting, addressing the question of whether integer operations can beat the comparison-sorting input/output (I/O) bound posed by Aggarwal and Vitter in 1988. We give a deterministic sorting algorithm: for $N$ integers of $Θ(\log N)$ bits, a memory holding $M$ integers, and block transfers of $B$ integers, where $2B\le M\le N$, the number of block transfers is $O\!\left(\frac{N}{B}\left[1+\frac{\log N}{(\log(M/B))^{1-\varepsilon}(\log M)^\varepsilon}\right]\right)$, where $\varepsilon=1.5\times10^{-5}$ is an absolute constant. In some parameter ranges, this bound is asymptotically smaller than the classical comparison-sorting bound. Under the external-memory model specified in this paper, we have formally verified the algorithm's correctness and I/O complexity bound in Lean.
Problem

The undirected multiple-unicast (Li–Li) conjecture states that network coding cannot beat fractional routing in undirected networks. If true, it implies conditional lower bounds showing that external-memory integer sorting cannot beat the comparison-sorting I/O bound, a question Aggarwal and Vitter posed in 1988.

Approach

The authors build a finite binary linear XOR circuit whose undirected network gives a strict coding advantage over routing, certified by an explicit numerical rate bound. Its linear structure is used recursively to speed up address-field interchange. That interchange is combined with Columnsort and most-significant-digit radix sorting into a deterministic external-memory sorting algorithm. Both main theorems are formalized in Lean 4 with Mathlib, under the paper's external-memory model.
