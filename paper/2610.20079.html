Undirected Multiple-Unicast Network Coding and Faster External-Memory Integer Sorting

Baochun Li, Zongpeng Li, Sirui Liu

TL;DR

Abstract
In undirected multiple-unicast networks, where independent messages are sent between specified source–destination pairs, network coding allows intermediate nodes to combine messages, whereas fractional routing splits and forwards individual messages along paths without mixing them. Proposed in 2004 by Li and Li and independently by Harvey, Kleinberg, and Lehman, the multiple-unicast conjecture—a central conjecture in network coding with deep connections to computational complexity—asserts that network coding and fractional routing have the same achievable rate region. We construct a counterexample refuting this conjecture and use it to reduce block transfers in external-memory data rearrangement, thereby accelerating external-memory integer sorting and answering in the affirmative the longstanding question of Aggarwal and Vitter (1988) on whether integer operations can beat the comparison-sorting input/output (I/O) bound. Specifically, we give a deterministic sorting algorithm: for $N$ integers of $Θ(\log N)$ bits, a memory holding $M$ integers, and block transfers of $B$ integers, where $2B\le M\le N$, the number of block transfers is \[ O\!\left(\frac{N}{B}\left[1+ \frac{\log N}{(\log(M/B))^{1-\varepsilon}(\log M)^\varepsilon} \right]\right), \] where $\varepsilon=1.5\times10^{-5}$ is an absolute constant. This bound asymptotically improves on the classical $Θ\!\left(\frac{N}{B}\left[1+ \frac{\log(N/M)}{\log(M/B)}\right]\right)$ comparison-sorting bound in certain parameter regimes. Under the external-memory model specified in this paper, we have formally verified the algorithm's correctness and I/O complexity bound in Lean 4.
Problem

The multiple-unicast conjecture holds that network coding and fractional routing achieve the same rate region in undirected networks. Aggarwal and Vitter (1988) asked whether integer sorting in external memory can beat the comparison-sorting I/O bound.

Approach

The authors build a finite XOR circuit, viewed as an undirected multiple-unicast network, in which binary linear coding strictly outperforms fractional routing. They use this circuit to speed up address-field interchanges. Combined with Columnsort and most-significant-digit radix partitioning, this yields a deterministic external-memory sorting algorithm. Correctness and the I/O bound are formally verified in Lean 4 with Mathlib under the paper's stated model.

Results

The circuit refutes the conjecture, with routing rate at most 1-33/338432 against a coding rate of 1. Sorting takes O((N/B)[1+log N/((log(M/B))^{1-ε}(log M)^ε)]) block transfers with ε=1.5×10^-5, which beats the comparison bound in some parameter regimes. The Lean proofs are kernel-checked with no unfinished proofs or extra axioms.
