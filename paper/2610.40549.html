Typed Transverse Momentum Parton distribution function computations

Dustin Keller

TL;DR
Lean 4 proves sound a finite-expression cache validator for TMD computations, including dependency soundness, substitution and interpretation laws, and fixed-slice transport, without Mathlib.
Abstract
A transverse-momentum-dependent parton distribution enters an extraction through a specified observation map and a parameter- dependent numerical calculation. Equal units and matching array dimensions do not establish that two implementations represent the same inference problem. We present typed-TMD, a computational framework that makes observation semantics, parameter dependencies, and admissible evaluation plans explicit.
Problem

Numerical arrays in transverse-momentum-dependent parton distribution (TMD) extractions can share units and dimensions while representing different observations. Caching a fitted dependency can change the function being optimized while leaving reference-point predictions unchanged.

Approach

typed-TMD combines Python runtime contracts, which record observation semantics, scientific context and statistical problem, with a finite-expression language that makes parameter dependencies and variation masks explicit. A checker for dependency-safe caching is proved sound in Lean 4.21.0: accepted plans preserve the full parameterized function on the declared variation domain for any fixed pure interpretation. A category of parameter interfaces with admitted substitutions shows how cached constructions compose. The framework is applied to an external arTeMiDe/SV19 Drell–Yan fit and to a two-parameter diagnostic regression.

Results

Lean checks dependency soundness, cache constancy, the concrete validator, substitution and interpretation laws, and fixed-slice transport. The Drell–Yan one-parameter fits and the reparameterization regression validate the runtime contracts, with four five-start external fits taking about 217 s.
