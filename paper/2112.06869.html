The Dry Ten Martini Problem at Criticality

Dan S. Borgnia, Matthew Faust

math-ph Dec 13, 2021 · v3 cond-mat.mes-hall quant-ph
formalization mathlib analysis physics
Read PDF arXiv abstract
TL;DR
The proof that all labeled almost Mathieu gaps are open is formalized in Lean 4 with Mathlib, with definitions files and a signature audit.
Abstract
We solve the dry ten martini problem (lean-verified this time) by showing that every labeled almost Mathieu gap is open for $λ\neq 0$ and every irrational frequency. In particular, we prove that the maximum logarithmic height of each labeled gap is non-decreasing in the coupling $λ$ and extend an initial open seed gap for each gap label $n$ from $λ\in(0,λ_{n})$ to all $λ> 0$. The non-decreasing property follows from restoring time-reversal symmetry to the almost Mathieu operator $H$ by pairing it with its magnetic inverse $\bar{H}$. This allows us to express the logarithmic coupling derivative of the maximal gap height as the expectation value of a non-negative operator, yielding the required monotonicity.
Problem

The dry ten martini problem asks whether every labeled spectral gap of the almost Mathieu operator is open for every nonzero coupling and every irrational frequency. A complete solution with a machine-checked proof is sought.

Approach

Time-reversal symmetry is restored by pairing the Harper operator with its magnetic inverse, obtained by anti-unitary complex conjugation in the symmetric gauge. The logarithmic coupling derivative of the maximal gap height is then written as the expectation value of a non-negative operator, which gives monotonicity. An initial open seed gap for each label is extended to all positive couplings using the Thouless formula and the Bourgain–Jitomirskaya formula. The argument is formalized in Lean using Mathlib only, with the help of AI tools, and an audit file checks the type and dependencies of the main theorem.

Results

Every labeled almost Mathieu gap is open for λ≠0 and every irrational frequency, and the maximum logarithmic height of each gap is non-decreasing in λ. The main theorem DryTenMartini.dry_ten_martini is verified in Lean, with mathematical constants drawn only from Lean's standard library and Mathlib.
