A Counterexample to Single-Control Null Controllability of Stochastic Heat Equations

Feizheng Huang, Zhaobo Liu

math.OC Nov 25, 2026 · v1

Read PDF arXiv abstract Code
TL;DR
The counterexample to single-control null controllability of stochastic heat equations comes with a Lean 4 formalization, published in a linked GitHub repository.
Abstract
We disprove the conjecture that a single localized drift control suffices for null controllability of stochastic parabolic equations with bounded adapted coefficients. On a bounded interval with homogeneous Dirichlet boundary conditions, we construct a deterministic, nonnegative smooth noise coefficient supported at positive distance from the control interval. One fixed nonzero smooth initial state cannot be driven to zero almost surely at any positive time by any progressively measurable control with finite expected $L^2$ energy. The proof uses products of Brownian increments in the adjoint terminal data to keep the initial pairing bounded away from zero while the observation norm tends to zero. On the flat torus, the construction yields counterexamples in every Gevrey class of order $s>1$ whenever the complement of the control set contains an open ball. Thus Gevrey regularity above order one cannot replace analyticity as a general sufficient condition for null controllability.
Problem

Lü and Zhang conjectured that a single localized drift control suffices for null controllability of stochastic parabolic equations with bounded adapted coefficients. Lü and Wang asked whether their analyticity assumption on the noise could be relaxed to Gevrey regularity of order greater than one.

Approach

On a bounded interval with Dirichlet conditions, the authors build a deterministic, nonnegative smooth noise coefficient supported away from the control interval. The adjoint backward equation is given terminal data containing products of Brownian increments over a partition of [0,T]. This keeps the pairing with the initial state bounded below while the observation norm on the control set tends to zero. The construction transfers to the flat torus using Gevrey cutoff functions, and the result is accompanied by a Lean 4 formalization.

Results

A fixed nonzero smooth initial state cannot be driven to zero almost surely at any positive time by any finite-energy control, which disproves the conjecture. On the torus, counterexamples exist in every Gevrey class of order s>1, while G^1 (analytic) coefficients still give null controllability.
