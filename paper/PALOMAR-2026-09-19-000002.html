TL;DR
Machine-checked Lean formalization of new lower and upper bounds for the planar weak (1,1) constant of the centred Hardy-Littlewood maximal operator over squares.
Abstract
Let c_d be the weak type (1,1) constant of the centred Hardy-Littlewood maximal operator over axis-parallel cubes in R^d: the least C such that alpha |{Mf > alpha}| <= C ||f||_1 for every integrable f and every level alpha. Its value is unknown for every d >= 2; in the plane the previously published lower bound is c_2 >= 3/4 - sqrt(2)/4 + sqrt(6)/2 = 1.62119... (Aldaz 2000) and the best known upper bound is 4. This development proves c_2 >= Phi = 1.68550999335552518..., an explicit algebraic number of degree 16, from a lattice with unequal masses: columns at spacing h = (5 + sqrt 22)/6 carrying masses alternating 1 and w = (17 + 4 sqrt 22)/9, rows at spacing h + 1. It also proves 1.685 < Phi < 1.686, the classical covering bound c_d <= 2^d in every dimension, and an upper bound below the classical one in the plane, c_2 <= 3.879, by comparing the maximal operator with an explicit kernel for the Cauchy generator -|D_u| - |D_v|.

Problem

The weak type (1,1) constant c_d of the centred Hardy-Littlewood maximal operator over axis-parallel cubes is unknown for every d >= 2. In the plane the best published bounds were 1.62119... <= c_2 <= 4.

Approach

The lower bound comes from a lattice of point masses with unequal weights. Columns sit at spacing h = (5 + sqrt 22)/6 and carry masses alternating 1 and w = (17 + 4 sqrt 22)/9, with rows at spacing h + 1. The upper bound compares the maximal operator with an explicit kernel for the Cauchy generator -|D_u| - |D_v|. The classical covering bound c_d <= 2^d is also proved in every dimension, and all results are formalized and machine-checked in Lean.

Results

The development proves c_2 >= Phi = 1.68550999..., where Phi is an explicit algebraic number of degree 16, and certifies 1.685 < Phi < 1.686. It also proves the improved planar upper bound c_2 <= 3.879 and c_d <= 2^d for all d.
