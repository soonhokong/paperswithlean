Amicable numbers

Paul Pollack

Read PDF arXiv abstract Code
TL;DR
The main upper bound on amicable numbers, found by ChatGPT Astra, was also formalized by it in Lean/Mathlib and kernel-checked using only standard axioms.
Abstract
Let $s(n):=\sum_{d\mid n,\,d < n} d$ denote the sum of the proper divisors of $n$. Distinct positive integers $n,m$ form an amicable pair if $s(n)=m$ and $s(m)=n$. Let $A(x)$ count the positive integers not exceeding $x$ that belong to an amicable pair. We report on a proof, found by ChatGPT Astra, that $$ A(x)\le x\exp\{-(1/2+o(1))\log x\,\log_3 x/\log_2 x\}$$ as $x\to\infty$. Here $\log_k$ denotes the $k$th iterate of the natural logarithm.
Problem

Let A(x) count the amicable numbers up to x. Earlier work gave upper bounds on A(x), the best being Pomerance's 2015 bound x exp{-(1/2+o(1)) sqrt(log x log_3 x)}. The question is whether this bound can be improved.

Approach

The proof was found by ChatGPT Astra. It uses a known bound on integers n with large gcd(n, sigma(n)). It also uses a new lemma, proved via Rankin's trick and Mertens' theorem, counting squarefree b whose sigma(b) has a large smooth part or many large prime factors. ChatGPT Astra also produced a Lean formalization of the main theorem.

Results

The main theorem is A(x) <= x exp{-(1/2+o(1)) log x log_3 x / log_2 x}, a substantial improvement over the previous record. The Lean proof was checked by Lean's kernel and depends only on propext, Classical.choice, and Quot.sound.
