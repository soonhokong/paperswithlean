Three omitted values and non-Blaschke point divisors in half-planes

Quanyu Tang, Bokai Cui, Wei He, Tao Hu, Yanyang Li, Ke Wang, Zijun Yu

TL;DR
The main theorem, a counterexample to Nevanlinna's half-plane problem, is formalized in Lean 4 with Mathlib using Codex and checked by multiple independent kernels.
Abstract
We construct a real meromorphic function $F$ on $\mathbb C$ such that $F^{-1}(\{0,1,\infty\})\subset\mathbb R$, while $F$ is not of bounded type in either half-plane. More strongly, for every $a\in\widehat{\mathbb C}\setminus\{0,1,\infty\}$, the $a$-point divisor in either half-plane fails the Blaschke condition. Thus the construction gives a negative answer to the half-plane bounded-type question arising from Nevanlinna's 1925 work. Postcomposition gives the analogous counterexample for any prescribed triple of distinct values in the Riemann sphere. The core construction and proof were generated during an autonomous run of GPT-5.6 Sol Ultra.
Problem

Nevanlinna's 1925 question asks whether a meromorphic function on the plane that omits three values in a half-plane must be of bounded type there. The question was open in the unrestricted case, without a finite-order or growth assumption.

Approach

The authors build a real meromorphic function F from the modular covering of the thrice-punctured sphere, composed with a conformal map onto a domain bounded by Farey edges. That domain lies just above a Gaussian-perturbed comparison domain, and Schwarz reflection extends the function across the real line. Green-function estimates show that the a-point divisors fail the Blaschke condition. The core construction was generated by an autonomous AI run, and Codex produced a Lean 4/Mathlib formalization of the main theorem.

Results

F satisfies F^{-1}({0,1,∞}) ⊂ ℝ, yet F is not of bounded type in either half-plane, which answers Nevanlinna's question negatively. Every a-point divisor with a outside {0,1,∞} fails the Blaschke condition. The formal proof was accepted by the Lean, NanoDa and con-ron kernels using only the standard axioms.
