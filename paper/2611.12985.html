Parametric Proof-Carrying Compilation for Quantum Error-Correction

John Zhuoyang Ye, Jens Palsberg

cs.PL Nov 8, 2026 · v2 quant-ph
verification formalization quantum
Read PDF arXiv abstract
TL;DR

Abstract
We present PC-QEC, a proof-carrying compilation framework for quantum error correction parameterized by both code distance and syndrome-extraction scheme. It covers all four schemes—Standard, Flag, Shor and Knill—with circuit-level distance guarantees for every legal code distance in each proved family under the declared error and readout contracts. The circuit-level model permits single-wire Pauli errors at every operation's qubit operands, capturing data errors, readout errors and ancilla errors that propagate into multi-qubit hook errors. For each family and scheme, supplied code-algebra and invariant proofs combine with proved scheme-specific propagation lemmas into a finite symbolic certificate whose size is independent of code distance. We demonstrate family-wide guarantees for five code families across all four schemes. For rotated Surface code, one Standard Scheme certificate proves a distance lower bound $d$ for every odd $d\ge3$ and checks in 214\,s on average. Lean 4 mechanizes the metatheory and exact circuit-level distances for canonical rotated Surface, unrotated Surface and Toric code families.
Problem

Circuit-level code distance of quantum error-correction circuits accounts for hook errors and readout faults. It is NP-hard to compute, and proofs for individual code distances do not extend to whole code families. A single finite proof is needed that covers every legal distance and different syndrome-extraction schemes.

Approach

PC-QEC is a proof-carrying compiler with three layers. CodeML specifies parametric code families and their ordered stabilizer schedules. QStab is an intermediate representation that tracks residual errors, readout offsets and fault budgets via a cut invariant. QClifford is a Hoare-style logic over emitted Clifford circuits with explicit fault sites. Code-algebra proofs and scheme-specific propagation lemmas for the Standard, Flag, Shor and Knill schemes combine into a symbolic certificate whose size does not depend on code distance. An OCaml verifier checks the certificates, and Lean 4 mechanizes the metatheory and the exactness results.

Results

Family-wide distance guarantees are demonstrated for five code families across all four schemes. A single Standard Scheme certificate for the rotated Surface code proves distance at least d for every odd d≥3 and checks in 214 s on average. Lean proofs establish exact circuit-level distances for the canonical Surface, unrotated Surface/HGP and Toric code families.
