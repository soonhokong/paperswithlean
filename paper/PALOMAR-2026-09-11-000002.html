TL;DR
Formalizes three forms of the Kolmogorov-Arnold representation theorem in Lean, with statements expressed purely in Mathlib vocabulary and machine-checked proofs.
Abstract
Every continuous real function on the closed unit n-cube is a superposition of continuous functions of one variable and addition, with the inner functions universal for the dimension. Three forms, each implying the next, named for who is credited with the statement. Lorentz-Sprecher form: there are positive constants lam_1, ..., lam_n and continuous strictly increasing psi_0, ..., psi_2n : R -> R, all depending only on n, such that every f continuous on [0,1]^n is f(x) = sum_{q=0}^{2n} g(sum_{p=1}^{n} lam_p psi_q(x_p)) on the cube for some continuous g : R -> R depending on f. Lorentz's form: continuous monotone (non-decreasing) inner functions phi_{q,p} : R -> R indexed by both q and p, and a single continuous outer function Phi. Kolmogorov's form: continuous phi_{q,p} and 2n+1 continuous outer functions Phi_q – the theorem as proved in 1957 and as usually cited. In every form the inner functions are quantified before f, so one family serves every f; that is the content of the theorem. The statements are made for every n, the trivial cases n = 0 and n = 1 included, and are written in Mathlib's vocabulary alone – Continuous, ContinuousOn, StrictMono, Monotone, Set.Icc on Fin n -> R and finite sums – with no definition of their own, so that each can be audited against the informal statement without first accepting a definition.

Problem

The Kolmogorov-Arnold representation theorem says every continuous real function on the closed unit n-cube is a superposition of continuous one-variable functions and addition. The inner functions are universal: one family chosen for the dimension works for every f.

Approach

Three forms are stated and proved, each implying the next. The Lorentz-Sprecher form uses positive constants and strictly increasing inner functions with a single outer g. Lorentz's form uses monotone inner functions phi_{q,p} and a single outer Phi. Kolmogorov's form uses continuous phi_{q,p} and 2n+1 outer functions Phi_q. All statements use only Mathlib notions (Continuous, ContinuousOn, StrictMono, Monotone, Set.Icc on Fin n -> R, finite sums) and introduce no custom definitions, so they can be audited directly against the informal statement.

Results

The statements cover every n, including the trivial cases n = 0 and n = 1. In each form the inner functions are quantified before f, and the registry machine-checked the proofs.
