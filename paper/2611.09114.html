Annular webs and Guralnick's conjecture

Tom Goertzen, Abel Lacabanne, Daniel Tubbenhauer, Pedro Vaz

math.RT Nov 6, 2026 · v1 math.CO math.GR
formalization algebra combinatorics
Read PDF arXiv abstract Code
TL;DR
A Lean formalization verifies the explicit affine Weyl group family, the web calculation, gallery counts, and the row-sum identity for all m ≥ 2.
Abstract
Using annular webs and Kazhdan-Lusztig mu-coefficients, we disprove Guralnick's absolute boundedness conjecture for first cohomology.
Problem

Guralnick's 1985 conjecture asserts an absolute constant bounding dim H^1(G,M) for faithful absolutely irreducible modules of finite groups. Earlier computations via affine Kazhdan–Lusztig mu-coefficients suggested growth with rank but could not be pushed further.

Approach

Annular webs serve as graphical guidance to identify Hom spaces with Hecke and Schur maps and to read affine KL coefficients from canonical webs. This yields an explicit affine family whose mu-coefficients sum to m(m+1)/2. A Lean development formalizes the affine family, the six-map web calculation, gallery counts, the canonical correction and the row-sum identity, and encodes the chosen web as a labeled graph.

Results

First cohomology dimensions are unbounded already for finite simple groups of type A, with dim H^1 ≥ ⌈(m+1)/2⌉, which disproves Guralnick's conjecture. Lean declarations row_sum and named_row_and_lower_bound state the main theorem and corollary.
