Monotone Local Search with Sample-Dependent Running Times

Serge Gaspers

cs.DS Nov 1, 2026 · v1 cs.DM
formalization verification mathlib combinatorics
Read PDF arXiv abstract Code
TL;DR
Parts of the running-time analysis, including the certificates and the correctness of the Steiner extension, are formally checked in Lean 4 with Mathlib in the ancillary files.
Abstract
Monotone Local Search turns an algorithm that extends a given partial solution into an algorithm that finds a solution from scratch: sample a few elements, hope that they lie in an unknown solution, and complete them. Its known analyses bound every call of the extension algorithm by a worst-case time that depends only on the number of sampled elements, and Esmer et al. (SODA 2024) showed that no algorithm that uses the extension algorithm as a black box with this running time beats the original form by more than a polynomial factor. We let this running time depend on the actual sample. If the extension algorithm decides in time $O^*(2^{g(I,X,k)})$, for a polynomial-time computable $g$, whether a sample $X$ can be completed to a solution with at most $k$ elements, our main theorem gives a randomized algorithm with one-sided error in time $O^*(2^{ψn})$ whenever, for some solution $S$ of size $k$ and some $t$, the exponential moment $\sum_{X\subseteq S,|X|=t}2^{-g(I,X,k)}$ is at least $2^{-ψn}\binom{n}{t}$. A corollary, multivariate Monotone Local Search, generalizes the theorems of Fomin et al. (STOC 2016, J. ACM 2019) and of Gaspers and Lee (ICALP 2017). For Max Leaf Spanning Tree and, equivalently, Connected Dominating Set, the previous best polynomial-space bound is $O^*(1.8619^n)$. Completing a sample is a Steiner tree problem, solved in time exponential in the number of terminals, which varies strongly with the sample. We obtain a randomized polynomial-space algorithm in time $O(1.6991^n)$ and a deterministic one in time $(\sqrt5-\frac12)^n 2^{o(n)}=O(1.7361^n)$. For connectivity problems in which the extension algorithm's running time doubles with every component of the sample, an analysis through a partition function gives randomized polynomial-space algorithms in time $O^*(1.8^n)$ for Connected Feedback Vertex Set and $O(1.6444^n)$ for Connected Vertex Cover.
Problem

Monotone Local Search bounds every extension call by a worst-case running time that depends only on the sample size, and a known black-box barrier prevents improvement beyond that model. The paper studies what can be gained when the extension algorithm's running time depends on the actual sample, with Max Leaf Spanning Tree / Connected Dominating Set as the main application.

Approach

A main theorem gives a randomized one-sided-error algorithm whose running time is governed by exponential moments of the running-time exponent over subsets of a solution. Samples above a threshold exponent are discarded. For Connected Dominating Set the extension step is a Steiner tree computation by inclusion–exclusion. The moments are bounded with tree potentials, three-state recursions and antinorm certificates, and closure sampling refines the bound. Certificates and parts of the analysis are verified in Lean 4 with Mathlib, mostly by the kernel alone, with the RSC certificate data checked by compiled evaluation.

Results

Polynomial-space algorithms for Connected Dominating Set / Max Leaf Spanning Tree run in randomized time O(1.6991^n) and deterministic time O(1.7361^n), improving on O(1.8619^n). Connected Feedback Vertex Set is solved in randomized O*(1.8^n) and Connected Vertex Cover in randomized O(1.6444^n). A multivariate Monotone Local Search generalizing earlier theorems is also obtained.
