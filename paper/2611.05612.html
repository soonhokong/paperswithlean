Whiel: A Neurosymbolic Platform for Certified Relational Program Verification

Jesse Comer, Fangzhu Shen, Shuo Zhang, Mayur Naik, Sudeepa Roy, Val Tannen

TL;DR
Builds a Lean library formalizing relational programs and Hoare logic soundness, and certifies LLM-found invariants and counterexamples as Lean-kernel-checked proofs.
Abstract
We present the Whiel (a contraction of Whi(le-R)el) system for Lean-certified reasoning about imperative relational programs. The system can encode containment and equivalence problems for Datalog, its extensions with negation, and the core fragment of graph query languages. It can also represent optimized or incremental evaluation algorithms that are not expressible in the original query language, as well as first-order specifications of integrity constraints, schema mappings, and views arising in data integration, exchange, and sharing. Whiel's program states are database instances, and its imperative structure enables compositional Hoare-style reasoning with first-order relational specifications, using prophecy variables and leveled invariants to support inductive arguments. Whiel supports neurosymbolic discovery of loop invariants whose verification conditions can be checked using the Vampire first-order theorem prover. Counterexamples are fed back into the neurosymbolic pipeline, while proposed solutions are translated into Lean proof certificates. To validate the Whiel system, we evaluate its performance on a curated benchmark suite. In summary, we envision the Whiel system as a tool for tackling mathematically demanding, typically undecidable problems involving complex query and constraint languages, with a high degree of trust in its output.
Problem

LLM-proposed solutions to hard, often undecidable database problems need correctness guarantees. Examples include query rewritings, Datalog evaluation strategies and incremental view maintenance algorithms. Testing and manual review cannot establish correctness over all databases.

Approach

Whiel encodes these problems as Hoare triples over imperative relational programs whose states are database instances. An LLM proposer (AgentHoudini) suggests invariant clauses or counterexamples. A LeveledHoudini verifier checks them with Vampire, using prophecy variables and leveled invariants. A Lean library formalizes the relational algebra, assertions, commands and Hoare logic soundness. A certifier then produces Lean proofs of validity by reconstructing Vampire proofs with VampLean, and certifies invalidity by replaying counterexamples in a Lean interpreter and model checker.

Results

Whiel was evaluated on a curated benchmark of 86 tasks (69 valid, 17 invalid). It solves substantially more tasks than baselines that write Lean proofs directly (DirectLean, 20 solved) or that make a single proposal without feedback (Whiel-OneRound, 46 solved). Certification reduces the trusted base to the Lean kernel.
