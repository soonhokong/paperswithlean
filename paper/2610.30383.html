Rank Ceiling for Twiddle-Perturbation Faults on the Forward NTT

Chakshu Gupta

cs.CR Oct 21, 2026 · v2

Read PDF arXiv abstract Code
TL;DR
Lean 4 with Mathlib certifies the one-fault-per-layer kernel equalities for the 256-coefficient forward and inverse NTT network shapes under twiddle replacements.
Abstract
NIST-standardised ML-KEM and ML-DSA use forward number-theoretic transforms on secret polynomials. This paper characterises the linear map from a polynomial to the difference between its correct and faulted transforms under static twiddle replacements. Each selected twiddle takes a fixed changed field value at every use during one call, including zeroing, nonzero replacements and qualifying bit flips. For one replacement, the difference-map rank equals the number of butterflies sharing that twiddle, halving by layer from 128 to 2 for ML-KEM and to 1 for ML-DSA. With one replacement per layer and the map and difference known, every coefficient is determined except the constant and linear coefficients for ML-KEM, or the constant for ML-DSA. Lean 4 certifies the corresponding kernel equalities for both 256-coefficient network shapes over fields of characteristic other than two with all original twiddles nonzero. The unresolved coefficients cancel from the transform difference for every allowed fault set. NIST permits seed storage, motivating comparison of a known correct public key with a released faulty key from the same seed. If only one ML-KEM secret-polynomial transform is affected and all other computations are unchanged, the decoded key difference is a known public-matrix column times the transform difference. An invertible column entry reconstructs the latter. For ML-DSA, reconstruction and exact candidate counts from paired compressed public keys are not established.
Problem

ML-KEM and ML-DSA apply forward number-theoretic transforms to secret polynomials. Faults that replace twiddle factors can leak information. No general rank-and-kernel law was known for the correct-minus-faulted transform difference under static twiddle replacements.

Approach

The paper defines a difference map between the correct and faulted NTT under fixed replacement values applied at every use of the selected twiddles. It decomposes the network into butterfly layers and uses invertibility of the unchanged layers to compute ranks. It then derives kernels for one-per-layer fault patterns and a universal kernel inclusion valid for any fault set. Lean 4.27.0 with Mathlib certifies the n=256 kernel equalities, and Python and Gaussian-elimination checks test the ranks numerically.

Results

A single replacement has rank equal to the number of butterflies sharing that twiddle, which halves by layer from 128. One replacement per layer gives rank 254 for ML-KEM and 255 for ML-DSA, and every coefficient is determined except the constant and linear coefficients (ML-KEM) or the constant (ML-DSA). For ML-KEM, a correct and a faulty public key generated from the same seed let an observer reconstruct the transform difference when the affected public-matrix column has an invertible entry.
