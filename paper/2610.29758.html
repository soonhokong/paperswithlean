AssureCode: Structured Justification for Trustworthy Agentic Coding

Logan Murphy, Wilson Sy, Rhys Balevicius, Kelsie Fung, Karenna Kung, Aren A. Babikian, Marsha Chechik

TL;DR
Uses Lean as the formalization backend and theorem prover for autoformalized intent specifications, decomposition-soundness proofs, and test-oracle alignment checks in agentic coding.
Abstract
The use of AI-based tools in software development is rapidly changing how software is produced, enabling large volumes of code to be generated with limited human implementation effort. However, this raises fundamental challenges for ensuring that generated artifacts are aligned with developer intent and have been appropriately validated. In this work, we propose the use of structured argumentation in driving AI-assisted software development. Inspired by techniques from assurance engineering for safety-critical systems, we define a language of justification rationales that explicitly relate informal natural language prompts, formal specifications, assumptions about developer intentions, and program analysis evidence in a structured and verifiable format. We then describe AssureCode, a tool-supported methodology for creating such rationales as part of agentic code generation. We provide an empirical analysis of our implementation where we investigate its capacity to contribute towards justified assurance of correctness for AI-generated code.
Problem

AI agents can generate large volumes of code, but it is hard to establish that this code is aligned with developer intent and has been adequately validated. Justification, meaning the reasons the evidence supports trust, is usually left implicit.

Approach

The authors define a language of structured justification rationales inspired by GSN assurance cases. These rationales relate prompts, partial first-order formalizations, assumptions, and program-analysis evidence. AssureCode, implemented as an MCP service, autoformalizes intent into Lean vocabularies and specifications for human approval. It then decomposes claims via Lean templates, with an agent proving decomposition soundness that Lean checks, and links tests to formal claims. The process also generates collateral validation obligations for human review.

Results

AssureCode was evaluated on samples from HumanEval, LiveCodeBench, and MBPP with four LLMs, against an iterative LLM 'vibe justification' baseline. A single AssureCode run produced a comparable number of validation obligations and recovered most of the concerns found by the baseline. It also surfaced additional concerns, with part of its coverage coming from the formalization artifacts.
