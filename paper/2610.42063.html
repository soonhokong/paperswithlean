Counting Square Tilings with a Fixed Set of Polyominoes Is #EXP-Complete

Qiuyu Chen, Baao Xie

cs.CC Oct 30, 2026 · v2
formalization combinatorics logic
Read PDF arXiv abstract Code
TL;DR
The authors provide a companion Lean 4 formalization of the #EXP-completeness result for counting fixed-polyomino square tilings.
Abstract
An important question in counting complexity is whether exact counting can remain hard under restrictions that make feasibility easy. Tilings of squares by a fixed family of polyominoes provide a stringent test of this question, since tileability is polynomial-time decidable and the only varying input is a binary-encoded side length. We prove that there exists a fixed finite family of connected polyominoes for which counting translation-only square tilings is #EXP-complete under polynomial-time metric reductions, while the counting function belongs to #E. The resulting separation reveals that solution multiplicities can retain computational information that feasibility alone cannot capture. The proof develops a two-stage numerical isolation technique that combines a boundary-amplified Wang system with a rigid geometric compiler to recover accepting-computation counts while controlling all noncanonical tilings.
Problem

Pak conjectured that counting translation-only tilings of an n×n square by a fixed finite family of polyominoes, with n given in binary, can be #EXP-complete, even though tileability is decidable in polynomial time.

Approach

A fixed counting machine is encoded so that its initial configuration is recovered from the binary side length, and its runs are simulated by Wang tile tableaux. A boundary-amplified Wang system gives the intended boundary class a dominant multiplicity. A rigid geometric compiler realizes the Wang system as connected polyominoes, and rectangular-dissection bounds control noncanonical tilings. A companion Lean 4 formalization of the completeness result is provided.

Results

There is a fixed finite family of connected polyominoes whose square-tiling counting function is #EXP-complete under polynomial-time metric reductions while lying in #E. This resolves Pak's conjecture.
