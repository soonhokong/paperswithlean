Certified Inference and Training for Deep Equilibrium Networks: A Continuation Framework with Polynomial Complexity Guarantees

Alex Borisevich

Abstract
We develop a certified continuation framework for inference and training in deep equilibrium networks (DEQs), with training posed as interpolation to accuracy $2^{-b}$. For inference, input homotopy selects an equilibrium branch from a supplied start root, and a rounded tracker follows it under quantitative conditioning, derivative, boundary, and tube-radius certificates. The framework includes structured factorized certificates, sequential block elimination, inheritance of contraction guarantees in adapted coordinates, and bordered continuation through simple folds. For smooth multidimensional DEQs, including tanh networks, rational local tests can construct and validate oriented continuation charts under explicit geometric promises. For training, programmable dormant bilinear rank-one channels provide output-preserving residual-aligned repairs. Loaded Tikhonov solves diagnose insufficient parameter-to-output directions, while certified gate realization, column stability, well-posed inference, and finite-update error budgets control each pass. Under polynomially bounded certificate, encoding, precision, and backend costs, both inference and training have bit complexity $O(\mathrm{poly}(L+b))$, where $L$ is the encoded instance length; training uses $O(b+\ell)$ passes and reserve channels from an initial residual bounded by $2^\ell$. A budgeted implementation returns either certified success or inconclusive termination. The quantitative core and local certificate machinery are machine-checked in Lean 4, while numerical experiments illustrate the training mechanism.
Problem

Deep equilibrium networks (DEQs) raise questions of equilibrium existence, solver selection, and computational cost, and training must control both the number of updates and per-update precision to reach a target accuracy. The goal is a certified framework with polynomial bit-complexity guarantees for both inference and training.

Approach

Input homotopy selects an equilibrium branch and a rounded tracker follows it under conditioning, derivative, boundary, and tube-radius certificates, using an exact low-rank reduction to bound the inverse Jacobian. Training is posed as interpolation to accuracy 2^{-b} using loaded Tikhonov solves that either succeed or diagnose a weak output direction, with dormant bilinear rank-one channels providing output-preserving repairs. A rational tanh evaluator gives a concrete backend with explicit work envelopes. The quantitative core and local certificate machinery are machine-checked in Lean 4.

Results

Under polynomially bounded certificate, encoding, precision, and backend costs, both inference and training achieve bit complexity O(poly(L+b)), with training using O(b+ℓ) passes. A budgeted implementation returns either certified success or inconclusive termination, and numerical experiments illustrate the training mechanism.
