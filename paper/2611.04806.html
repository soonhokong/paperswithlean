On the Complexity of Finite-Sum Nonconvex-Strongly-Concave Minimax Optimization with Exact Proximal Oracles

Abstract
Finite-sum nonconvex-strongly-concave minimax problems arise in adversarial training and distributionally robust learning. Known lower bounds for these problems cover only linear-span algorithms, zero-respecting algorithms, or a restricted proximal protocol. This leaves open whether unrestricted adaptivity or exact component proximal steps, which return global saddle points of regularized component problems, can improve the polynomial complexity. We show that they cannot. Consider $n\ge2$ components with joint mean-squared smoothness $L$ and condition number $κ\ge1$, and a starting point with primal gap at most $Δ$ and joint gradient norm at most $\sqrt{2LΔ}$. For $\varepsilon^2/(LΔ)$ below a universal constant, every randomized adaptive algorithm with exact component values, gradients, and proximal responses requires at least $Ω(n+\min\{\sqrt n\,κ,n^{3/4}\sqrtκ\}LΔ/\varepsilon^2)$ expected component queries in the worst case to find an $\varepsilon$-stationary point of the value function. A method that uses only component gradients attains this rate up to a factor $\log^2(2+κ)$, including its initialization cost. Zhou (arXiv:2610.04944) concurrently proves the same rate for zero-respecting first-order methods. For large condition numbers, our hard instances link primal stages through dual paths whose edges belong to random components, and with high probability a proximal query to a component reveals a path only up to the first edge owned by another component.
Problem

Known lower bounds for finite-sum nonconvex-strongly-concave minimax optimization cover only linear-span, zero-respecting, or restricted proximal algorithms. It was open whether unrestricted adaptivity or exact component proximal oracles could improve the polynomial complexity.

Approach

Hard instances chain nonconvex primal stages through dual paths whose internal edges are owned by random components. A proximal query reveals a path only up to the first edge owned by another component, which forces many serial owner searches. A matching upper bound combines SPDE updates, recursive variance-reduced gradients, L-SVRE steps, and Catalyst acceleration. The existential lower-bound assertions are formalized in Lean, using a finite Rademacher construction in place of Haar-distributed axes.

Results

Every randomized adaptive algorithm with exact values, gradients, and proximal responses needs Ω(n + min{√n κ, n^{3/4}√κ} LΔ/ε²) expected component queries. A gradient-only method matches this up to a log²(2+κ) factor. The Lean supplement verifies the lower bound in all three condition-number ranges.
