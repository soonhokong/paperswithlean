ZFLean: a framework for set-level mathematics in Lean

Vincent Trélat, Matteo Pouillat

cs.LO Apr 27, 2026 · v3

Read PDF arXiv abstract Code
TL;DR
Builds a Lean 4 library on Mathlib's ZFC model, adding a relational calculus with tactics, canonical set constructions, and bridges to native Lean types.
Abstract
We present ZFLean, a Lean 4 library for doing core mathematics inside a model of ZFC with the ergonomics expected of typed Mathlib developments. Building on Mathlib's ZFC model, we contribute a relational calculus for sets with rewriting hints and small predictable tactics, canonical set-theoretic constructions – Booleans, naturals, integers, sums/option – and bridges between ZFC objects and Lean's native types enabling mixed set-level/typed proofs. The layer reduces boilerplate for extensional reasoning while remaining compatible with vanilla Mathlib. We discuss library organization and usage patterns that lower the friction of set-theoretic formalization in a dependently typed assistant. We demonstrate typical use of the framework with a case study exercising our constructions and relational calculus through a proof of an isomorphism theorem on curried functions.
Problem

Set-level mathematics inside a typed proof assistant tends to be verbose and brittle. Partial maps need encodings, extensionality must be handled with discipline, and moving to native types is manual. As a result, Mathlib's ZFC model is more often referenced than used for real developments.

Approach

ZFLean extends Mathlib's ZFC model (pre-sets quotiented by extensional equivalence) with a relational calculus. The calculus covers converse, identity, composition, domain, range and image, plus rewriting hints and small tactics (zrel, zpfun, zfun) that discharge well-formedness side-conditions. It defines canonical ZFC objects with their universal properties: Booleans, naturals, integers, rationals, function spaces, sums and options. Bridges via Lean subtypes connect ZFC objects to native Lean types, supporting mixed set-level and typed proofs.

Results

The library stays compatible with vanilla Mathlib and reduces boilerplate in extensional reasoning. A case study proves the currying isomorphism C^(A×B) ≅ (C^B)^A inside the framework, exercising the constructions and the relational calculus.
