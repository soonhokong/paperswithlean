Abstract
A Lean+mathlib proof of Nivat's conjecture: Given a finite alphabet A, we consider configurations c: Z^2 -> A, which are arbitrary maps that can be thought of as colorings of the 2D lattice. Writing P_c(m, n) for the number of distinct m-by-n block patterns occurring in a configuration c, Nivat conjectured that if P_c(m, n) <= mn for some positive m and n, then c is periodic; that is, there exists nonzero h such that c(v+h) = c(v) for all v. The proof is due to GPT-6 Pro.

Problem

Nivat's conjecture concerns configurations c: Z^2 -> A over a finite alphabet A, with P_c(m, n) counting the distinct m-by-n block patterns in c. It states that if P_c(m, n) <= mn for some positive m and n, then c is periodic: some nonzero h satisfies c(v+h) = c(v) for all v.
