ScenicProver: A Framework for Compositional Probabilistic Verification of Learning-Enabled Systems

Eric Vin, Lucy Horowitz, Kyle A. Miller, Inigo Incer, Sanjit A. Seshia, Daniel J. Fremont

cs.LO Nov 4, 2025 · v2 cs.AI cs.LG cs.PL
verification logic probability
Read PDF arXiv abstract
TL;DR
Proof-based evidence and contract refinements in assurance cases are checked as Lean 4 proofs using LeanLTL, including nonlinear-arithmetic refinement proofs in the case study.
Abstract
Full verification of learning-enabled cyber-physical systems (CPS) has long been intractable due to challenges including black-box components and complex real-world environments. Existing tools either provide formal guarantees for limited types of systems or test the system as a monolith, but no general framework exists for compositional analysis of learning-enabled CPS using varied verification techniques over complex real-world environments. This paper introduces a tool, ScenicProver, that aims to fill this gap by enabling the construction of sound, formally-checked assurance cases for CPS. ScenicProver is backed by a formal theory, which we lay out in this paper. ScenicProver supports: (1) environment modeling using the Scenic probabilistic programming language; (2) compositional system modeling with clear component interfaces, ranging from interpretable code to black boxes; (3) assume-guarantee contracts over those components using an extension of Linear Temporal Logic containing arbitrary Scenic expressions; (4) evidence generation through testing, formal proofs in Lean 4, and external assumptions; (5) sound combination of generated evidence using contract operators with Pacti; and (6) automatic generation of assurance cases tracking the provenance of system-level guarantees. We demonstrate its effectiveness through two case studies: one on an automatic emergency braking system with sensor fusion and one on drone safety. By leveraging manufacturer guarantees for sensors and focusing testing effort on uncertain conditions, our approach enables stronger probabilistic guarantees than monolithic testing with the same computational budget.
Problem

Verifying learning-enabled cyber-physical systems as a whole is intractable because of black-box ML components and complex environments. Monolithic testing also cannot reuse component-level guarantees such as sensor manufacturer specifications.

Approach

ScenicProver models environments with the Scenic probabilistic programming language and splits systems into components with assume-guarantee contracts written in an LTL extension containing Scenic expressions. Evidence comes from testing, from Lean 4 proofs via LeanLTL, and from external assumptions. The evidence is combined soundly with contract operators (composition, conjunction, refinement, strong merging, and a new weak merging operator), mostly computed by Pacti. Lean proofs are used where an operation is undecidable or Pacti cannot compute it. The tool then generates assurance cases that track where each guarantee came from.

Results

Two case studies were run: an automatic emergency braking system with sensor fusion and a drone safety system. With the same compute budget, the compositional approach gave stronger probabilistic guarantees than monolithic testing, for example about 0.946 versus 0.916 after 480 minutes.
