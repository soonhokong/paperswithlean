Schur decomposition with logarithmic precision in cubic time up to logarithmic factors

Matthew J. Colbrook

TL;DR

Abstract
How much arithmetic precision is needed to compute a Schur decomposition to a prescribed tolerance? Let $A$ be a complex matrix of order $n$ with spectral norm at most one, let $0<δ<1/2$ be the tolerance, and let $0<p<1/2$ be the requested failure probability. Our randomised floating-point algorithm uses $O(\log(n/(δp)))$ mantissa bits per real component and $O(n^3\log^2(n/(δp)))$ arithmetic operations on every execution, with universal constants. It returns $Q$ and an exactly upper triangular $T$. With probability at least $1-p$, both $\|A-QTQ^*\|_2$ and $\|Q^*Q-I\|_2$ are at most $δ$. We sample a small perturbation using finitely many bits and use Gaussian estimates to bound the eigenvector conditioning and eigenvalue gap. A single contour estimate bounds the effect of a rounding error through any number of remaining Newton steps. At each subdivision level, the full matrix is unitarily similar to a small perturbation of the regularised input. This allows us to bound the conditioning of each diagonal block directly from that input and to use the same precision throughout.
Problem

How much floating-point precision is needed to compute a Schur decomposition of a complex matrix to backward error δ with failure probability p? The question is whether O(log(n/(δp))) mantissa bits suffice in near-cubic time, avoiding the extra logarithmic factor in precision (Simons workshop Problem 3.3).

Approach

A randomised algorithm perturbs the input with a finitely sampled Gaussian matrix. Gaussian estimates bound eigenvector conditioning and the eigenvalue gap. Spectral subdivision then uses Newton matrix-sign iterations, and a single contour estimate controls rounding errors through all remaining Newton steps. At each subdivision level the full matrix stays unitarily similar to a small perturbation of the regularised input, so diagonal-block conditioning is bounded directly and the same precision is used throughout. The main theorem was also formally verified in Lean.

Results

The algorithm uses O(log(n/(δp))) mantissa bits and O(n^3 log^2(n/(δp))) operations. It returns Q and an exactly upper triangular T with ‖A−QTQ*‖ ≤ δ and ‖Q*Q−I‖ ≤ δ with probability at least 1−p. The proof was found by AI and is presented in human-digestible form.
