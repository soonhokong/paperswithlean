Lyapunov stability of polynomial vector fields is undecidable

Milan Korda

math.DS Sep 18, 2026 · v2 math.CA math.OC

Read PDF arXiv abstract
TL;DR
The Main Theorem, undecidability of Lyapunov stability for homogeneous polynomial vector fields, is formalized in Lean, with the formalization produced by AI models.
Abstract
We show that there are integers $N$ and odd $D$ such that no algorithm can decide, from the rational coefficients of a homogeneous polynomial vector field $F$ in dimension $N$ of degree $D$, whether the origin is Lyapunov stable for $\dot Y=F(Y)$. This proves a conjecture of V. I. Arnold. We provide a Lean formalization of the proof. The smallest dimension $N$ for which we were able to prove undecidability is $N = 5$. An analogous undecidability result holds for global asymptotic stability and global exponential stability for non-homogenous vector fields. For dimension $N=2$ and homogenous vector fields, we establish decidability for all commonly used stability notions, building heavily on existing results.
Problem

Arnold conjectured that no algorithm can decide whether the origin is Lyapunov stable for a polynomial vector field with rational coefficients of fixed degree and dimension. The work settles this conjecture.

Approach

A register machine with undecidable halting is simulated by a clocked ODE, using sample-and-hold, cubic relaxation and growing gain so that error bounds hold uniformly over all initial states. The ODE is then algebraized into a polynomial system with an accumulated-output functional, using smoothing, auxiliary radicals, a penalty and a time change. A projective lift turns this system into a homogeneous polynomial field whose stability is equivalent to halting. The Main Theorem is formalized in Lean; some later remarks are not.

Results

There exist N and odd D for which Lyapunov stability of homogeneous degree-D polynomial fields in dimension N is undecidable; the smallest dimension obtained is N = 5. Analogous undecidability holds for global asymptotic and exponential stability of non-homogeneous fields, and all common stability notions are decidable for homogeneous fields in dimension 2.
